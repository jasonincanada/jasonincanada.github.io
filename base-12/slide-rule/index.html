What each scale does

The logarithmic scales are recut for base twelve. Values sharing the cursor’s hairline are mathematically related.

K
Cubes and cube roots. A value on D lines up with its cube on the three-cycle K scale.
A
Squares and square roots. The fixed, two-cycle square scale paired with D.
B
Moving square scale. Pairs with A for square-scale multiplication, division, and proportion.
CI
Reciprocals. A reversed C scale: each value occupies the position of its inverse, making division and chained operations easier.
C
Moving multiplier. Set its index over the first factor on D, then find the second factor on C.
D
Fixed value and product scale. The primary reference scale where results are normally read.
L
Base-12 logarithms. A linear scale from 0 to 1; a value on D aligns with its log₁₂ value on L.
